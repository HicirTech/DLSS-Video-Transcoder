# runtime/

This folder is intentionally empty in the repository. Nothing from NVIDIA is
redistributed by this project. Place the files you are licensed to use here,
each in the feature folder shown:

| File | Role | Where it comes from |
| --- | --- | --- |
| `dlssnr/nvngx_dlssnr.dll` | DLSS 5 Neural Rendering runtime (NGX feature 18) | Shipped with DLSS 5 titles and recent GeForce drivers. Official builds only enable RTX 50. |
| `dlss/nvngx_dlss.dll` | DLSS Super Resolution runtime (optional upscale stage) | NVIDIA DLSS SDK on GitHub, or any DLSS game folder |
| `dlssg/nvngx_dlssg.dll` | DLSS Frame Generation runtime (NGX feature 11); required by `fg` and by frame generation in the web UI | NVIDIA DLSS SDK on GitHub |

`_nvngx.dll` (the NGX core) is never copied here; it is loaded from the
installed display driver. `nvngx.dll` inside `runtime/caller/` is generated by
this project itself (see `src/ngx/forwarder.ts`) and can be deleted at any time.
