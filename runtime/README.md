# runtime/

This folder is intentionally empty in the repository. Nothing from NVIDIA is
redistributed by this project. Place the files you are licensed to use here;
each one is needed only for its own feature:

| Path | Needed for | Where it comes from |
| --- | --- | --- |
| `dlssnr/nvngx_dlssnr.dll` | Neural Rendering, NGX feature 18 (`nr`, `video --nr`); the probe's readiness check | Shipped with titles that use DLSS Neural Rendering. Official builds only enable RTX 50. |
| `dlss/nvngx_dlss.dll` | Super Resolution, NGX feature 1 (`sr`, `video --sr`) | NVIDIA DLSS SDK on GitHub, or any DLSS game folder |
| `dlssg/nvngx_dlssg.dll` | Frame Generation, NGX feature 11 (`fg`, `video --fg` and the web UI's frame generation) | NVIDIA DLSS SDK on GitHub |
| `ffmpeg/bin/ffmpeg.exe`, `ffmpeg/bin/ffprobe.exe` | Video, when ffmpeg is not on `PATH` or set by `FFMPEG_PATH` / `FFPROBE_PATH` | Any ffmpeg build |

Extra versions of a DLL go one folder deeper, one folder per version, for
example `dlss/310.7.129.0/nvngx_dlss.dll`; `bun run src/cli.ts versions` lists
everything it finds, together with the DLSS Swapper cache. Each feature can be
switched to one of those versions (`sr --dlss-version`, `fg --dlss-version`,
`video --sr-version`, `--nr-version` and `--fg-version`, and each step's version
picker in the web UI); without one, the DLL directly in the feature's folder is
loaded.

`_nvngx.dll` (the NGX core) is never copied here; it is loaded from the
installed display driver. `caller/nvngx.dll` is generated by this project and
can be deleted at any time.
